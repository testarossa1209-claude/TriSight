トライルール・トライリワード・トライグラント・トライケアの各システムは、ここに並ぶエンジンを部品として使います。エンジンはどの子にも属さず、同じ一つのものを皆で共有します。

子システムからの呼び方

子システムの画面に次の1行を入れると、6つのエンジンを同じ書き方で呼べます。H&Nパトリオットの判定規則はこの部品の中で凍結してあり、呼び出す側から書き換えることはできません。

<script src="TriEngines.js"></script>

TriEngines.open('triform');                 // 画面を開く
TriEngines.read('trisheet');                // エンジンが残した結果を読む（基本情報の元帳）
TriEngines.send('triform', 案件);            // TriForm／TriTaskへ案件を渡す
var r = TriEngines.patriot.check(
          TriEngines.patriot.fromText(会話ログ)); // 自分の理論に撃ち込む
// r.D＝逸脱量　r.rate＝効力を削る割合（％）　r.hits＝該当した型
